I am a software engineer and university lecturer with a background in software engineering, computer science, and applied AI.

My MSc research was on object detection for mobile robot navigation in dynamic indoor environments. Most of my software work is in full-stack systems, APIs, academic platforms, data products, and computer vision. I have also worked on realtime 3D browser interfaces using Three.js and WebGL.
